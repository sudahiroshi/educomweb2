# 決定事項（decision.md）

日本音響学会 音響教育委員会 Webサイト（asj-edcom.acoustics.jp）リニューアルについて、チャットでの議論で決定した事項の記録。
番号（D-xx）は参照用。変更する場合は削除せず「変更」として追記する。

最終更新：2026-11-19

---

## 1. 全体方針

- **D-01** 旧サイト（管理者がHTMLを直接編集、フレーム構成、ISO-2022-JP）は引き継がず、静的サイトジェネレータ **Astro** で作り直す。
- **D-02** 既存コンテンツは引き継ぎつつ、デザインを一新する。
- **D-03** 記事の作成・プレビュー・出力を行う **編集画面** を作る。サーバー側の動的処理は持たず、ブラウザだけで動く静的ページとする。
- **D-04** 実装作業は Claude Code で行う。チャットでは仕様書の作成までを行う。

## 2. コンテンツの種類と単位

- **D-05** 「お知らせ」は1件ずつ日付付きの投稿とする。
- **D-06** 旧サイトの「最近の活動」と「過去の主な活動」は統合し、**「活動記録」** とする。
- **D-07** 「運営委員」は **年度ごとの名簿ページ** とする。
- **D-08** 「音響学会研究発表会」「共催研究発表会」「国際会議」は、**1回の開催で1記事** とする。
- **D-09** 上記以外の旧サイトのページ（委員会紹介など）は、それぞれ **独立したページ** として作り、リンクする。
- **D-10** お知らせ等と同様に、**その他のページにも編集画面を用意する**。

## 3. 記事の項目

- **D-11** **掲載日** と **開催日** を区別する。
- **D-12** 研究発表会・国際会議の記事は、会場、セッション名、講演一覧、外部リンクを持つ。
- **D-13** 活動記録も、研究発表会と同じ項目（会場、外部リンクなど）を持つ。
- **D-14** 開催日は **開始日と終了日** を持つ。開始日のみの場合は1日開催とみなす。
- **D-15** 講演一覧は **表形式** とし、**1回の開催に複数セッション** を持てる。
- **D-16** 各セッションは、セッション名に加えて **日時・会場（部屋）・座長・副座長** を持つ。
- **D-17** 講演一覧の発表者欄には **1名のみ** 載せ、2人目以降の著者がいる場合は **「他」** と表記する。
- **D-18** 外部リンクは **1記事に複数** 持てる。
- **D-19** 運営委員の名簿は **役職・氏名・所属** の3列とする。
- **D-20** お知らせから **研究発表会等の記事へリンク** できる欄を設ける。

## 4. 一覧と並び順

- **D-21** 研究発表会・共催研究発表会・国際会議の記事は、記事ごとに **「活動記録に載せる」チェック** で活動記録への掲載を選べる。
- **D-22** 一覧は **開催日順・新しい順（最新が上）** とする。
- **D-23** これから開催されるものは **「開催予定」** として一覧の上に並べる。開催予定の欄の中は **開催日の近いものが上**。
- **D-24** 開催予定から終了への切り替えは、**ビルド時に振り分け**、加えて **閲覧時にブラウザ側で日付を判定** して、ビルド後に終了したものも正しく振り分ける。
- **D-25** 判定は終了日（なければ開始日）の **翌日0時（日本時間）** に「終了」に切り替える。
- **D-26** 終了した予定は **年度（4月〜3月）ごと** に分けて表示する。
- **D-27** 年度ごとの表示は、一覧ページに直近の年度を載せ、**過去の年度は年度別ページに分けて** リンクを並べる（ページネート）。
- **D-28** 運営委員ページは **最新年度を表示** し、**過去年度へのリンク** を並べる。

## 5. ナビゲーション

- **D-29** その他のページは **メインメニュー** に出す。
- **D-30** 研究発表会3種は **サブメニュー**（「研究発表会・国際会議」の下）にまとめる。
- **D-31** スマートフォンでは折りたたみメニューにする。

## 6. 移行

- **D-32** 移行範囲は **旧サイトの全期間** とする。
- **D-33** 旧サイトは移行後に閉鎖するため、**旧URLの維持・リダイレクトは行わない**。
- **D-34** 添付ファイル（PDF・画像など）は引き継ぎ、新サイトのファイル置き場にまとめ、リンクを書き換える。
- **D-35** 旧サイトのデータ（HTML・添付ファイル一式）は **すべて確保できる**。

## 7. 公開・運用

- **D-36** ソースは **GitHub** で管理する。
- **D-37** 公開は **Cloudflare** で行う（GitHubへのpushで自動ビルド・公開）。
- **D-38** ドメインは現行の `asj-edcom.acoustics.jp` を使う。acoustics.jp のDNS設定は学会事務局と **調整できる見込み**。
- **D-39** **複数のメンバー** が記事を追加できるようにする。メンバーは **全員GitHubアカウントを持つ** 前提とする。
- **D-40** メンバーは **管理者の承認なしに直接公開** してよい。
- **D-41** 入力ミス対策として、**Astroのスキーマで項目をチェック** し、不備があればビルドを失敗させ、本番は直前の状態のまま残す。編集画面でも同じチェックを行い、不備があれば出力できないようにする。

## 8. 編集画面

- **D-42** 編集画面は **本番サイト内の、メニューに出さないURL** に置く。
- **D-43** 出力は、ファイルのダウンロードに加えて、**「GitHubに追加」ボタンでGitHubの新規ファイル作成画面を、ファイル名と内容を入れた状態で開く** 方式を採用する。
- **D-44** 画像付き記事は次の流れとする。
  1. 編集画面で画像を選ぶと、規則的な名前に付け替えてプレビューに表示する
  2. 名前を付け替えた画像をまとめてダウンロードする
  3. 「画像をGitHubにアップロード」で保存先フォルダのアップロード画面を開き、ドラッグ＆ドロップする
  4. 「記事をGitHubに追加」で記事ファイルを作成する
- **D-45** zip出力は、GitHubを使わずに管理者へ渡す場合の **予備の出力** として残す。
- **D-46** 本文は **Markdown** で書き、よく使う書式は **ボタンで挿入** できるようにする。
- **D-47** 出力した `.md` を **読み込んで修正・再出力** できるようにする。

## 9. 表示設定・デザイン・機能

- **D-48** **ライト／ダークモード** を切り替えられる。初期値は **OSの設定に従い**、切り替えたら **ブラウザに記憶** する。
- **D-49** **文字サイズ** をノーマル（100%）・大（125%）・特大（150%）から選べる。**ページ全体** が対象で、**ブラウザに記憶** する。
- **D-50** デザインは **案B「音のモチーフ」** を採用する（波形のあしらい、角丸カード、青緑のアクセント、Zen Kaku Gothic New）。
- **D-51** 案Bのライトモードは、背景を明るく（#FDFDFB）、文字を黒（#0A0A0A）にしてコントラストを上げる。
- **D-52** **サイト内検索**（ビルド時に索引を作る静的検索）と **RSS** を入れる。
- **D-53** アクセシビリティは **JIS X 8341-3 のAA相当** を目標とする。

## 10. 未決事項から決定したもの

- **D-54** GitHub リポジトリの **オーナーは管理者の個人アカウント** とし、**公開リポジトリ** にする（T-09）。公開のため、編集画面は既存記事一覧から GitHub の raw URL で記事を直接読み込める（spec 6.7）。
- **D-55** デザイン案Bのトップページを **ライト・ダークの画像2枚** に書き出し、リポジトリの `docs/design/` に保存する（T-30）。
- **D-56** `events` の種類に **メディア出演**（`kind: media`）を加える（2026-11-23）。一覧は `/media/`（構成は活動記録と同じ、年度別ページあり）、記事詳細は `/media/{id}/`。メインメニューでは **活動記録の次** に置く。
